This is the first stop on a beginner's path to using Claude Code in your
academic work — teaching and research alike. You don't need to have installed
anything yet — this post is pure orientation. By the end you should be able to
say, in your own words, what Claude Code is and whether the rest of this path is
worth your time.

## What Claude Code is

[Claude Code is an AI assistant](https://code.claude.com/docs/en/overview) that works directly with the files on your own
computer. It can read them, edit them, and run commands on your behalf — and you
drive it by typing instructions in plain English into a text prompt (a window
called the "terminal"). You stay in control the whole time: by default it
explains what it's about to do and asks your permission before it changes
anything.

That last part is the important bit. Claude Code isn't a chatbot that lives in a
separate window and hands you text to copy. It works *inside* your project
folder, on your actual files, documents, and notes.

## This guide assumes a Mac

Everything in this series is written for **macOS**. The ideas apply to Windows
too, but the specific instructions — how to install things, what the menus look
like — differ. A separate PC-focused guide may come later. If you're on a Mac,
read on.

## How it's different from the Claude website

If you've used Claude in a browser, the difference is worth making explicit:

- **Browser chat** is copy-and-paste. You paste text in, Claude answers, you
  copy the answer back out into your own files. Claude never touches your
  documents directly.
- **Claude Code** acts on your real project folder. It can open a file, change
  it, create a new one, or run a command — then show you exactly what it did. It
  keeps track of the context of your project across a whole working session, and
  it asks before making changes.

Put simply: the website *talks*; Claude Code *does*.

## What it's good for

A few concrete examples, drawn from teaching and research:

- **Taming a messy project folder.** You have a directory with a tangle of data
  files, half-finished drafts, figures, and stray downloads from a paper. Claude
  Code can read through it, describe what's there, and help you reorganize it
  into something sensible.
- **Writing and revising alongside your files.** Tightening the argument in a
  working paper, reformatting a results table, smoothing the prose of a referee
  response, or polishing a syllabus — all done in place, in the document itself,
  not in a separate window.
- **Turning scattered notes into structure.** Hand it a pile of rough reading
  notes or lecture jottings and ask for a clean outline, a lecture plan, or a
  first-draft problem set you can then edit.
- **Building something small.** A quick figure from a CSV, a tidy table from raw
  numbers, a short script to reshape a dataset — this very website is itself a
  Claude Code project. You don't need to be a programmer to point it at a simple
  task and get a working result.

The theme: it's most useful when the work lives in files on your computer — data,
drafts, course materials — and you want a capable assistant working *with* those
files, not beside them.

## What it's NOT

Claude Code is a powerful assistant, not an oracle. It can be **confidently
wrong** — stating an incorrect fact, or inventing a citation, quote, or statistic
in the same authoritative tone it uses when it's right. And it's no substitute for
your judgment: it's your work, and you stay the reviewer of record.

:::caution
Treat everything Claude produces as a draft to check, not a verdict to trust —
especially citations, page numbers, quotes, and numbers, which it can fabricate
without warning. Verifying its work is the one non-negotiable habit, and it gets a
whole page later: [Trust, Safety & Integrity](/ai/trust-safety-integrity/).
:::

None of this is a reason to avoid the tool — it's a reason to use it the way you'd
use a sharp but green assistant: helpful, fast, and always reviewed.

## What you'll need to follow along

- A **Mac** (macOS 13 or later).
- A **paid Claude plan** — Pro is the usual starting point; Max also works, and
  institutions may use Team or Enterprise. The **free plan does not include
  Claude Code**. (There's also a pay-as-you-go API option, but a Pro
  subscription is the simplest path for most people.)
- About **30 minutes** for one-time setup.
- A willingness to experiment. You genuinely can't break anything by reading and
  trying.

ready.
