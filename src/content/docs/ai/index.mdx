This is a beginner's guide to getting started with **Claude Code**, the AI tool I
use most — written by **Bryan Cutsinger**, an economist at Florida Atlantic
University (and interim director of the AIER Sound Money Project), for other
economists. The examples lean on academic life: cleaning a dataset, tightening a
working paper, drafting a problem set. No prior experience needed — we start from
zero and build up. It's free, self-paced, and updated as the tools change: no
sign-up, no paywall, no consultation gate. (For Anthropic's own reference, see the
[official quickstart](https://code.claude.com/docs/en/quickstart).)

:::note[How to read this guide]
The guide has a short **required path** and a longer shelf of chapters you pull in as you
need them. The required path is just the first two groups — **Set up** (decide and
install) and **Get oriented** (the core working loop and how to steer it). Finish those
and you're self-sufficient. The rest — **Work on real projects** and the **Reference**
section — is next-stage reading for when you point Claude at a real paper, dataset, or
course, or want a specific capability. None of it is a checklist to finish before you
start.
:::

## What you'll need

A short, honest list before you start. The whole setup takes about thirty minutes.

| What | Details | Needed? |
| --- | --- | --- |
| A Mac | macOS 13 (Ventura) or later | Yes |
| A paid Claude plan | Pro is the usual starting point; Max also works. The free plan does **not** include Claude Code. | Yes |
| Visual Studio Code | Free editor from Microsoft — your home base. We install it early in the setup chapter. | Yes |
| About 30 minutes | One-time setup, done once. | Yes |
| A willingness to experiment | On a practice folder you genuinely can't break anything — keep your real data and drafts out until you're ready. | Recommended |
