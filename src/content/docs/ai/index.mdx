This is a beginner's guide to getting started with **Claude Code**, the AI tool I
use most. It's written for **fellow economists on a Mac** — for the work of
teaching and research — who have never used a command line or an AI coding tool.
The examples lean on academic life: cleaning a dataset, tightening a working
paper, drafting a problem set. No prior experience needed — we start from zero
and build up. (For Anthropic's own reference, see the [official
quickstart](https://code.claude.com/docs/en/quickstart).)

It's written by **Bryan Cutsinger**, an economist at Florida Atlantic University
(and interim director of the AIER Sound Money Project), for other economists — and
it's free, self-paced, and updated as the tools change. No sign-up, no paywall, no
consultation gate.

## What you'll need

A short, honest list before you start. The whole setup takes about thirty minutes.

| What | Details | Needed? |
| --- | --- | --- |
| A Mac | macOS 13 (Ventura) or later | Yes |
| A paid Claude plan | Pro is the usual starting point; Max also works. The free plan does **not** include Claude Code. | Yes |
| Visual Studio Code | Free editor from Microsoft — your home base. We install it early in the setup chapter. | Yes |
| About 30 minutes | One-time setup, done once. | Yes |
| A willingness to experiment | On a practice folder you genuinely can't break anything — keep your real data and drafts out until you're ready. | Recommended |
