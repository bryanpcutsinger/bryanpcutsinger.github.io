These pages exist to keep a two-hour working session on track and to stay useful long after it ends. Treat this run of show as the agenda during the session and as a checklist you can revisit on your own afterward — each segment links to a page that walks through the same material at your own pace.

The session is built for an economics professor and department chair on Windows who already has the Claude desktop app installed. The aim is simple: leave able to do real work on your own, not just to have watched a demo.

## The agenda

| Time | Segment | Goal |
| --- | --- | --- |
| 0:00–0:15 | Warm-up & orientation | Get comfortable with the desktop app and its three tabs — Chat, Cowork, and Code. |
| 0:15–0:45 | First Cowork task | Connect a practice folder and run one real Cowork task end to end, with approval. |
| 0:45–1:15 | A real research or teaching task | Apply Cowork to your own work — a course or research artifact you actually use. |
| 1:15–1:35 | A taste of Code | See the Code tab and a live diff: a change shown for you to accept or reject. |
| 1:35–2:00 | Safety, integrity & next steps | Lock in the approval and verification rules, and leave with a plan. |

## By the end you will have…

- Run two real Cowork tasks from start to finish, approving the plan each time.
- Seen a Code diff and approved (or rejected) a change in real time.
- Internalized the approval model and the integrity rule: every citation, number, and quote gets checked against the original source.
- A practice folder set up and a short list of next steps for your own teaching, research, and chair work.

:::tip[For the facilitator]
Protect the two hands-on blocks above all else — the first Cowork task (0:15–0:45) and the real research or teaching task (0:45–1:15) are where the learning actually happens. Keep the opening tab tour short; people retain far more from running one task than from a walkthrough of menus. If Cowork runs long, it is completely fine to skip the Code tab segment entirely and spend that time getting a real result. Code is a bonus, not the point.
:::

## Before and after the session

If you want to arrive ready, skim [Before We Meet](/ai/desktop/before-we-meet/) first — it covers what to have installed and which folder to practice on. For the bigger picture of what Cowork and Code are, start from the [branch overview](/ai/desktop/). And if you ever want the command-line version of these tools, Anthropic's [Claude Code quickstart](https://code.claude.com/docs/en/quickstart) covers it — the desktop app shares the same engine and configuration.

:::caution
Whichever segment you are in, the integrity rule does not change: Claude can produce confident-sounding citations, page numbers, quotes, and data that are wrong. Anything that will appear in a paper, syllabus, or memo to your department must be checked against the original source before you rely on it.
:::
