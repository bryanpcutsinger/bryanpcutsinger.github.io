The goal of the session is to spend two hours on real work — a syllabus, a dataset, a budget memo — not on installs and logins. This page is a 15-minute checklist to do beforehand so you arrive ready. None of it is hard, and if something gets stuck, that is exactly what the session is for. Show up with the snag and we will sort it out together.

If you have not yet, skim the [Start here overview](/ai/desktop/) for the big picture, and take a look at the [run of show](/ai/desktop/session-run-of-show/) so you know what the two hours will cover.

## The checklist

Work through these in order. Each one has a quick note on *why* it matters.

### 1. Confirm a paid plan and that you are signed in

Cowork and the Code tab are **paid features** — the free plan does not include them. The entry plan, Pro, is about **$17/month billed annually ($20 month-to-month)** and includes everything we will use. Open the app and confirm your name and plan appear in account settings; if you see "Free," upgrade before the session so we are not waiting on a payment screen.

*Why:* the whole session depends on these tools being available. This is the one item most likely to block us, so do it first.

See the current plans on [Anthropic's pricing page](https://claude.com/pricing).

### 2. Open the app and find the three tabs

You already have the desktop app installed. Launch it from the **Start menu** (search "Claude" if you do not see it pinned). At the top you should see three tabs: **Chat**, **Cowork**, and **Code**. You do not need to do anything with them yet — just confirm all three are there.

*Why:* knowing where the tabs live means we can jump straight into Cowork instead of hunting for buttons. If a tab is missing or greyed out, that usually points back to item 1 (plan or sign-in).

:::tip[See it on Anthropic's site]
Looking for the tabs? Once the app opens, **Chat**, **Cowork**, and **Code** sit
across the top of the window. Anthropic's [desktop
quickstart](https://code.claude.com/docs/en/desktop-quickstart) shows where they are.
:::

If you want the full tour, the [desktop app overview](/ai/desktop/the-desktop-app/) walks through what each tab does.

### 3. (Optional) Install Git for Windows — only if you want to try the Code tab

We may spend a few minutes on the **Code tab** for a taste of what it can do. On Windows, the Code tab's local sessions need a free helper called **Git for Windows**. If you would like to try Code, install it ahead of time from [git-scm.com/downloads/win](https://git-scm.com/downloads/win) — accept the default options in the installer.

*Why:* Git for Windows is the one Windows-specific gotcha for Code. **Cowork does not need it** — so if you only care about Cowork, you can skip this entirely.

:::tip
Not sure whether you want to try Code? Install Git anyway. It is small, free, and harmless to have. Worst case, you do not use it.
:::

### 4. Make a practice folder of non-sensitive files

On your **Desktop**, create a new folder (call it something like `Claude Practice`) and drop in a few **copies** of low-stakes files — say 2 or 3 PDFs, one spreadsheet, and some notes. Use copies, not your originals.

Hard rule on what goes in:

- Nothing **confidential**
- Nothing **under review** (no manuscripts you are refereeing, no submissions)
- **No student records** (grades, rosters, anything covered by FERPA)

*Why:* Cowork reads and writes files in the folders you connect to it, so we want a safe sandbox to practice in. Working with copies means there is nothing to worry about if a first attempt goes sideways.

:::caution
Treat the practice folder as the *only* place Claude can touch during the session. Keeping sensitive material out of it is the simplest safety habit there is. We will cover the rest of the safety model when we [work with Cowork safely](/ai/desktop/cowork-safely/).
:::

### 5. Skim the pre-read pages

Spend a few minutes on the short pre-read so the session is hands-on rather than lecture. At a minimum, look at:

- [The desktop app](/ai/desktop/the-desktop-app/) — what the three tabs are for
- [Meet Cowork](/ai/desktop/meet-cowork/) — what Cowork is and how it works
- [Working with Cowork safely](/ai/desktop/cowork-safely/) — the approval model and what to watch for

*Why:* skimming ahead means we can spend the two hours *doing* instead of explaining basics. You do not need to memorize anything — just get the lay of the land.

### 6. Bring one real-but-low-stakes task

Come with a single task you would genuinely love to hand off, but where a rough first draft is fine. Ideas, depending on your week:

- **Teaching:** turn a set of lecture notes into a problem set, or draft a rubric from an assignment prompt.
- **Research:** clean and summarize a small dataset, or pull the key tables out of a few working papers into one comparison sheet.
- **Department-chair admin:** draft a budget summary in Excel from last year's numbers, or turn meeting notes into an agenda and action items.

*Why:* the session is far more useful when it is your real work, not a toy example. Low-stakes keeps the pressure off while you learn the workflow.

:::tip
Whatever the task, you stay the expert. Claude can draft, organize, and calculate — but it can also **fabricate citations, page numbers, quotes, and data values** that look completely plausible. Anything that will end up in a paper, a syllabus, or a budget gets checked against the original source before you rely on it. That habit is non-negotiable for academic work, and we will reinforce it throughout. (See [How Cowork Works Safely](/ai/desktop/cowork-safely/) for more.)
:::

## That's it

Six items, about fifteen minutes. If you get through them, you are fully ready. If you get stuck on any of them — the plan, the tabs, the Git install — **stop and bring the snag to the session.** Sorting out exactly these kinds of bumps is part of what the time is for, so a stuck step is not a failure; it is a head start on the conversation.
